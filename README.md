# NovaBrew Coffee Taste Profile Quiz

A personality-based coffee matching quiz built for NovaBrew Coffee Co. Answer seven questions and get matched with your coffee personality and a signature brew recommendation.

## Coffee Personalities

- **Bold Explorer** — Adventurous, intense, drawn to strong points of view. Matched with *Double Down*.
- **Smooth Operator** — Polished, balanced, effortlessly composed. Matched with *Velvet Fog*.
- **Cozy Classic** — Warm, grounded, and ritual-oriented. Matched with *Sunday Paper*.
- **Wild Card** — Curious, creative, drawn to the unexpected. Matched with *Off the Map*.

## About

Built as a customer personalization prototype for NovaBrew to improve subscriber retention through taste-profile matching. The quiz gives every new subscriber a clear coffee identity from day one, turning a transactional subscription into a personal relationship.

## Built With

- Vanilla HTML, CSS, and JavaScript
- Premium minimal design with bold serif typography
- Fully responsive — works on mobile
